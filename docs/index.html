◆ CSS-only · No JavaScript runtime · No build step

Semantic HTML,
beautifully styled.

lumen.css is a CSS-only, CSS-variable-configurable, semantic-first framework for productive business applications. Link the stylesheet — your semantic HTML is already styled.

<link rel="stylesheet" href="lumen.css" />

Why lumen.css

Everything you need. Nothing you don't.

A framework built around the principle that good HTML is already meaningful — styling should follow semantics, not fight against them.

CSS only

Zero JavaScript runtime, zero build step for consumers. Drop in one stylesheet and ship.

Token-driven theming

Every visual decision is a CSS custom property. Override any semantic token on :root to match your brand instantly.

Semantic-first

Element selectors and ARIA attributes drive all styling. No startup classes required — valid HTML is styled HTML.

Light & dark themes

Automatic via prefers-color-scheme. Override per-page with data-theme="dark" or data-theme="light".

Accessible by default

WCAG 2.1 AA contrast, visible focus rings, prefers-reduced-motion support, and logical properties throughout.

No layout system lock-in

Native CSS Grid and Flexbox handle layout. lumen.css provides the shell; you own the geometry.

Modern browser baseline

Chrome/Edge 121+, Firefox 121+, Safari 17.2+. Leverages :has(), color-mix(), and container queries without polyfills.

Built for business apps

Data tables, command menus, notification centers, toasts, layout shells, tabs — the primitives serious applications actually need.

Quick start

Up and running in one line.

No npm install. No webpack. No PostCSS pipeline. Just a <link>.

1. Link the stylesheet

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0" />
  <title>My App</title>
  <link rel="stylesheet" href="lumen.css" />
</head>
<body>
  <h1>Hello world</h1>
  <p>Semantic HTML, already styled.</p>
  <button type="button" data-tone="accent">
    Get started
  </button>
</body>
</html>

2. Customise tokens (optional)

/* Override any semantic token on :root
   before or after the import */
:root {
  --color-accent:       #7c3aed;
  --color-accent-hover: #6d28d9;

  --font-family-base:
    "Inter", system-ui, sans-serif;

  --radius-md: 0.5rem;
  --radius-lg: 0.75rem;
}

Responsive behavior

  • At ≤ 48em the sidebar slides off-canvas (transform: translateX(-100%))
  • Add data-open to aside[data-layout-sidebar] to reveal it
  • The panel track is collapsed on narrow viewports; main fills full width
  • prefers-reduced-motion: reduce disables the slide transition

Layout tokens 

:root {
  --layout-shell-header-height:
    3.5rem;
  --layout-shell-sidebar-width:
    clamp(14rem, 20vw, 20rem);
  --layout-shell-panel-width:
    20rem;
  --layout-shell-gap: 0px;
}

Light & dark theming

The dark theme activates automatically via prefers-color-scheme. Override with a single attribute on <html>.

Manual override

<!-- Force dark -->
<html data-theme="dark">

<!-- Force light -->
<html data-theme="light">

JavaScript toggle 

document.documentElement.setAttribute(
  'data-theme',
  document.documentElement
    .getAttribute('data-theme') === 'dark'
    ? 'light'
    : 'dark'
);

Use the Dark / Light toggle button in the header to toggle this page's theme — all components react instantly.
